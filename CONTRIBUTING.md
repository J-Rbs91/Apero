# Contribuer

## Style

- Le caractère tiret cadratin (`—`, em-dash) est **interdit dans tout texte
  visible ou audible par un·e utilisateur·rice final·e** : JSX/HTML rendu,
  libellés, boutons, messages d'erreur ou de confirmation, e-mails, exports
  (PDF, image, calendrier), métadonnées de page (titre, description, OG),
  textes alternatifs et `aria-label`.
- Préférez une virgule, un point (deux phrases), des parenthèses, un deux-points,
  ou un tiret simple entouré d'espaces (` - `) selon ce qui se lit le mieux.
- Le tiret cadratin reste toléré dans les commentaires de code et la
  documentation interne (`docs/`, `README.md`, etc.), tant qu'ils ne sont pas
  affichés dans l'application.
